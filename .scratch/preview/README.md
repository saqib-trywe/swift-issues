# Component gallery

`swift run issues-preview` renders every shared component with every sync surface
visible at once. It is the successor to ticket 10's HTML prototype and is just as
throwaway — nothing ships with it.

`gallery.png` is a capture of it, kept so the components can be reviewed without
running anything.

`windowid.swift` finds the preview window so a screenshot can be scoped to that
window alone. Capturing the whole screen would pick up whatever else is open.
