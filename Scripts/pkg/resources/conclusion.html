The server is running on 127.0.0.1:8080, under a LaunchAgent that starts it again at login.

Your first login needs the setup token, printed once on first run:
cat ~/Library/Logs/Issues/server.log

The issues command and the MCP server are in ~/.local/bin. Add it to your PATH if it is not there already.

To remove all of this later: issues-server uninstall. It leaves your data alone and tells you where it is.
